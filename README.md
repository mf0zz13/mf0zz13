# Hi, I'm Michael Foster

I'm completing a bachelor's degree in Computer Science with a concentration in Software Engineering. My primary interests are C#/.NET backend development, cloud-connected applications, and the testing and debugging work that makes software dependable.

## Featured project: Refuse Dispatch System

My most substantial application work is a multi-client C#/.NET dispatch system for coordinating trucks, employees, routes, and daily service records. It combines an [ASP.NET Core API](https://github.com/mf0zz13/RefuseServiceAPI) with a [Blazor WebAssembly management portal](https://github.com/mf0zz13/RefuseManagementPortal) and a [.NET MAUI Blazor Hybrid mobile client](https://github.com/mf0zz13/RefuseServiceApp), using Dapper, MySQL, JSON APIs, and Azure deployment workflows.

The system demonstrates application design across a shared operational workflow: field staff can create dispatch assignments, while managers can review current fleet activity and historical records. It remains a portfolio prototype, and its component repositories document the planned authentication, database-safety, testing, configuration, and deployment work required before production use.

My background also includes Microsoft Software and Systems Academy (MSSA) coursework in C#/.NET software development. My [individual assignments](https://github.com/mf0zz13/automatic-garbanzo) cover user interfaces, collections, data structures, algorithms, serialization, and LINQ, while my [team coding exercises](https://github.com/mf0zz13/vigilant-waffle) document collaborative problem-solving practice.
